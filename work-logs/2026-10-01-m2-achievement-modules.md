# M2 学术成果、竞赛成果与结构化自定义模块

## 目标与实现

- 新增 `academic`（学术成果）和 `competition`（竞赛成果）；新增自定义模块使用相同结构。
- 条目支持标题、个人角色、起止月份、至今、可选链接与带格式工具栏的正文。PDF 标题/角色同行、日期靠右，正文前留 4 px。
- 扩展 v1 契约：新类型要求明确的元数据字段；旧 `custom` 的新字段可缺省，不在读取时写回或增加修订。旧标题、正文、隐藏条目和排序保留。
- 旧获奖经历的直接正文模式保持；带新结构的自定义模块不再因改名为“获奖经历”而误隐藏标题/角色。
- 模块选择与新条目工厂统一；新增模块后选中对应页签。「至今」清空结束时间并禁用结束月份输入。

## 验证进度

- 111 项 Python 回归、42 项 Node 测试通过；新增类型和字段的契约、旧数据兼容、日期/URL/角色校验、渲染、复制与备份往返已覆盖。
- 成果模块 10 项真实 HTTP/PDF 检查通过：新字段编译、同行布局、链接、隐藏记录、旧自定义、无效数据拒绝、重启、独立副本和全新数据库备份导入；原后端一页/两页基准也通过。
- 新模块 PDF 经 Poppler 整页目视，无标题/日期错位、缺字或重叠。PDF 链接附近普通 text visitor 会在矩阵恢复后回调；布局断言使用保留位置的 layout 提取模式，避免把实际同行链接误判为换行。
- 8771 隔离浏览器逐一新增学术、竞赛、自定义，填写标题/角色/月份/正文并生成一页 PDF；至今勾选会清空/禁用结束月份，刷新后字段保留，无控制台错误或警告。
- 旧自定义打开时显示空的新增字段，仍为原修订；没有自动迁移写入。新模块在 390×844 窄屏中表单宽度/滚动宽度均为 332 px，页面宽度 390 px；补齐了选中页签自动滚入视野。
- 所有测试使用隔离虚构数据，不往用户简历插入示例内容。截图 `docs/m2/achievement-modules.jpg` 仅含虚构数据。
- 窄屏修正后实际验证选中页签完全位于容器内，已恢复默认视口。8770 已更新并载入用户最新 r36，未改写用户内容；重新编译到当前版本，模块管理已显示两个新类型和结构化自定义入口。
