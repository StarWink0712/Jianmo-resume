# 正文格式按钮

教育、工作/实习、项目、学术成果、竞赛成果、技能、获奖和自定义模块的每个正文框均带工具栏。

| 按钮 | 操作 |
| --- | --- |
| 加粗 | 选中文字后点击，再点可取消；无选区时插入并选中“加粗文字”供替换 |
| 斜体 | 选中文字后点击，再点可取消；无选区时插入可替换文字 |
| 换行 | 光标处插入显式换行，不加黑点/编号；有选区时在选区后换行，不删除所选文字；支持 Shift+Enter |
| 黑点列表 | 当前行或选中的多行添加 `- `；PDF 显示为黑点，再点可取消 |
| 编号列表 | 当前行或选中的多行添加 `1. `、`2. ` 等编号，再点可取消 |
| 撤销/重做 | 撤销/重做当前正文框的文字与格式操作 |

编辑区仍是 Markdown 源码，不是所见即所得编辑器。`**文字**` 是加粗标记，行首 `- ` 是列表标记；PDF 隐藏这些语法标记并呈现相应格式。无需手动输入黑点字符。
支持 ⌘/Ctrl+B、⌘/Ctrl+I、Shift+Enter、⌘/Ctrl+Z、⌘/Ctrl+Shift+Z，亦支持 Ctrl+Y 重做。
鼠标点击按钮保留选区，按钮可通过 Tab 聚焦并用 Enter 激活。格式结果计入 10000 字符上限；超出时提示并保留原文。

格式操作和普通输入一样自动保存；PDF 需点击“保存并预览”更新。不同正文框的历史独立，最多保留 100 步；切换模块保留，刷新页面清空。撤销不等于删除数据库中的历史版本。
中文输入法组字期间不执行格式命令，不提交中间组字状态，组字结束后沿用自动保存。
列表命令保留缩进；与相邻普通段落之间补空行，避免普通段落被 Markdown 解释为前一条的延续。原始 HTML/TeX 禁止规则和最多两层列表限制不变。

## 同一条目内换行

例如在同一个正文框中写多篇论文，把光标放在第一篇末尾，点“换行”或按 Shift+Enter，再写 `[2]` 和下一篇内容。`[1]`、`[2]` 是普通文字，不会变成黑点。

按钮生成 CommonMark 的“行末两个空格 + 换行”，PDF 中显示新的一行，仍使用固定正文行高。已有单个换行时，可把光标放在换行符前或下一行开头点击按钮，升级为明确换行，不会额外插入空段落。正文保存、备份、撤销/重做均保留换行标记。

普通 Enter 仍是 Markdown 软换行，PDF 中可能合并为空格；需要段落间距时空一行。行末反斜杠的 CommonMark 换行也支持，但无需手写。这里没有增加 HTML `<br>` 或原始 LaTeX 输入能力。

## 验证

```bash
node --test tests/markdown-model.test.mjs tests/style-model.test.mjs tests/resume-library.test.cjs
.venv/bin/python -m unittest discover -s tests
.venv/bin/python -m scripts.check_markdown_toolbar
```

模型覆盖选区、取消、混合加粗/斜体、多行与空行、列表转换、邻接段落、Unicode、历史隔离和步数上限。
PDF 回归从实际前端转换函数获取 Markdown，真实编译后检查粗体/斜体字体、黑点数量、编号、字体嵌入和语法标记不外露。
内嵌浏览器实测按钮、快捷键、跨模块历史、超限拒绝、刷新持久化和当前 PDF；默认桌面及 390×844 窄屏通过。
这不是完整浏览器兼容或真实输入法全覆盖验收，尚需独立 Safari/Chrome 与系统输入法专项测试。
