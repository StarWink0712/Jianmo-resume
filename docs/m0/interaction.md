# 页面流程与状态规则

交互稿：同目录 `editor-wireframe.html`，配套 `editor-wireframe.css`、`editor-wireframe.js` 和可单独测试的 `resume-library.js`。只验证布局和操作语义，不接入数据库、网络接口或 LaTeX，不代表 M1 已通过。

## 简历管理入口

默认进入“我的简历”：显示名称、求职方向、最近保存时间、草稿状态和副本来源，可搜索、新建、编辑、创建副本、重命名、删除。删除有明确目标及确认弹窗，取消不改数据。

新建可选择空白或虚构示例；创建副本默认读取已保存版本，源简历有未保存修改时允许显式改选当前草稿。创建后直接进入新简历的编辑器，原简历不变。副本拥有独立修订且没有已编译 PDF。

编辑器上方显示“我的简历”返回入口、当前简历选择器、重命名和创建副本。切换与返回列表保留每份简历各自的页面内草稿、标签、缩放和模拟预览。异步任务只更新发起任务的那一份简历，不覆盖后来切换到的其他简历。管理页缩略图基于各自草稿，只是示意，不是 PDF 缩略图。

当前管理操作只作用于本次页面内存。刷新或关闭会清空这些演示数据，不应录入真实个人资料；页面顶部持续显示这个限制。

## 布局基线（2026-10-01 修订）

按用户指定的卡码简历页面参考布局：紧凑顶部导航、左右等宽双栏、左侧横向模块标签、左右独立滚动、底部固定操作栏。采用白底、浅灰边框与蓝色操作按钮；不复制第三方品牌、真实简历、会员或水印功能。

```text
顶部：本地简历 / 我的简历 / 简历编辑 / 使用说明 / 本地优先 / M0 标识
提示：保存、编译与导出均为模拟
左侧简历编辑器                         右侧简历预览
  模块管理 / 排版设置                    缩放 / A4
  基本信息、教育、工作、项目等横向标签     当前或过期修订 / 非 PDF 标识
  当前模块表单（独立滚动）                整份简历纸张示意（独立滚动）
  [固定] 保存状态 / 流程测试 / 保存       [固定] 旧版导出 / 备份 / PDF 导出
```

窄窗口改为上下排列，标签横向滚动；字号设置在弹窗中，异常场景选择收进“流程测试”，不长期占用表单空间。默认预览适应宽度，75%/100% 缩放仅影响查看，不创建内容修订。

初次打开右侧即显示完整虚构样例，但明确标记“尚未编译 / 排版示意”，导出按钮禁用。它不等于成功 PDF；首次点击“保存并预览”才得到模拟成功快照。

## 可操作的原型内容

- 基本信息：姓名、电话、邮箱、城市、求职方向、个人主页；不加入参考站的年龄、性别或政治面貌等额外字段。
- 模块：每类一个示例条目，可修改标题、补充信息及正文；预览始终显示整份简历，不随选中标签切换为单条预览。
- 文字工具：插入受限 Markdown 标记，仍按原文展示，不宣称已实现 Markdown AST 或 LaTeX 渲染。
- 模块管理：显隐、上移/下移；隐藏保留内容。条目也有独立显示选项。
- 排版：有限字号、行距调整，需保存形成新模拟快照后显示。
- 头像：使用或隐藏合成轮廓，仅模拟，不上传、不读取本地照片。
- 键盘：横向标签支持左右箭头、Home、End；弹窗支持 Esc 关闭；旧版导出取消不得复用上次确认。

所有变化只保留在内存中，刷新即重置。完整多条目、日期表单、真实附件、数据备份与持久化仍留待后续阶段。原型的内部演示数据不替代正式 JSON Schema。

## 必须区分的状态

| 场景 | 保存区 | 预览区 | 默认导出行为 |
| --- | --- | --- | --- |
| 新建未编译 | 模拟已保存 r1 | 初始虚构样例，尚未编译 | 禁用 |
| 输入中 | 有未保存修改 | 上次成功 rN，已过期 | 禁用最新版，允许显式选择旧版 |
| 保存请求中 | 正在模拟保存 | 原成功快照保留 | 等待 |
| 保存失败 | 保存失败，输入保留，可重试 | 上次成功 rN，已过期 | 不冒充新版 |
| 保存成功、编译中 | 模拟已保存 rN+1 | 正在编译，保留旧版 | 等待或显式导出旧版 |
| 编译成功且目标匹配 | 模拟已保存 rN+1 | 当前快照 rN+1 | 允许模拟导出 |
| 编译失败/超时 | 已保存 rN+1 | 失败原因，上次成功 rN | 重试或显式导出旧版 |
| 旧任务晚到（生产规则） | 不变 | 不覆盖当前目标结果 | 不变 |
| 多标签页冲突（生产规则） | 冲突，保留本地输入 | 不误标为最新 | 重新加载或另存新简历 |

生产保存防抖目标约 1 秒，编译防抖只从成功保存快照触发，计时预算待 M1 校准。当前演示使用手动保存及短延时。页面内部切换会保留草稿，但关闭/刷新保护、多标签页冲突和真实编译竞争尚未实现，不能把原型演示视为这些测试已经通过。

## 人工走查脚本

1. 打开交互稿进入“我的简历”，编辑初始虚构样例，确认模拟提示、尚未编译标识和禁用的导出按钮。
2. 点击“保存并预览”，得到模拟快照 r1；切换横向标签，右侧仍保留完整简历。
3. 修改任意字段，确认未保存状态、旧预览保留并标记过期，最新版导出禁用。
4. 打开“流程测试”，选择“模拟保存失败”，关闭弹窗后保存；输入保留，修订不递增。
5. 改为“模拟编译失败”再保存；保存修订递增，预览仍为旧修订。
6. 点击旧版导出并确认；再修改内容、重开弹窗并按 Esc，不能产生新的导出提示。
7. 恢复正常场景重试，当前快照更新，导出只显示模拟提示，不下载 PDF。
8. 模块管理中上移项目、隐藏技能，保存后检查右侧顺序与显隐；恢复显示后原文应仍在。
9. 修改字号，保存后检查新快照；切换 100% 与适应宽度，横向溢出只能发生在明确放大的预览内部。
10. 在桌面、390 px 和 320 px 宽度下检查布局；通过方向键切换标签、Tab 遍历控件、Esc 关闭弹窗。

多简历补充走查：创建副本并修改姓名/方向，保存后切回原简历确认内容未变；再切回副本确认独立预览。制造未保存修改，分别验证默认复制已保存内容和显式复制当前草稿。验证重命名、空白名称拒绝、删除取消、空白新建与搜索无结果状态。自动模型测试另覆盖删除原简历仍保留副本、全部删除后空列表、并行任务归属及晚到任务拒绝。
