# M2 顶部空间与英文简历验证

## 范围与实现

- 将连接提示、简历切换、返回、重命名与副本操作放在同一顶栏。桌面端由原来的 30px 提示加 45px 上下文栏改为 45px，共节省 30px。
- 主编辑区按实际剩余高度伸展，不再假设顶栏固定为两行；字体告警或窄屏换行也不会覆盖编辑区。窄屏保留完整提示并换行，不隐藏错误信息或操作按钮。
- 用户授权的英文 PDF 经提取与人工核对后，新建独立的本机测试简历，保留六个模块、八条论文/专利及原有经历。未替换任何已有简历。
- 新增全英文虚构夹具与隔离 HTTP/TeX 回归脚本，提交的样例及证据不含真实姓名、联系方式或原简历文本。

## 英文实测发现与修复

- 自动英文断词会在导出的文字中添加连字符，导致严格文本完整性检查误报；现禁止自动插入断词连字符，原文已有的连字符仍保留并可作为换行位置。
- 原来的固定 `2em` 应急伸展不足以容纳部分长词；改为在页边距生效后使用行宽的 10% 作为最后换行尝试的伸展量。不修改字号、不删除文字，也不忽略溢出检查。
- fontspec 对正文默认启用 TeX 标点映射，会将直引号、撇号及连续连字符变形。对正文/无衬线字体显式关闭该映射；原样保留文字，正常粗体、斜体及字体内连字仍可用。
- 完整性检查与越界检查均未放宽。新英文夹具在 12px 和 14px 下均实际编译成功。

## 本机数据与提交边界

- 真实简历仅存本机 `.local-data/`，测试输入、备份、截图与诊断放在忽略的 `tmp/`，最终测试 PDF 放在忽略的 `output/pdf/private/`。以上均不进入本地 Git 提交。
- 本轮按用户要求只提交本地仓库，不推送远端。
- 这是英文内容/排版验证，不是完整界面国际化，也不是通用 PDF 自动导入。日期仍使用结构化年月；“至今”和部分自动链接标签的语言切换尚未实现，此英文样例使用明确结束日期及英文 Markdown 链接。
- 使用现有安装运行时的引擎与字体，通过 M2 源码后端编译；没有重打冻结运行时安装包或恢复已跳过的干净 Mac 验收。
