# M2 正文格式工具栏

## 目标与改动

- 为所有模块的正文框增加加粗、斜体、黑点列表、编号列表、撤销和重做按钮。
- 选区操作保留正文与光标；列表作用于当前行或选中多行，重复点击取消。保留 Markdown 存储与现有安全渲染路径，不引入富文本 HTML。
- 文本框明确提示 `- ` 是 Markdown 列表标记，在 PDF 中显示为黑点。格式操作走既有自动保存流程，PDF 仍需点击“保存并预览”。
- 增加快捷键及按正文框隔离、有上限的编辑历史；切换模块不清空历史，页面刷新不保存撤销栈。中文输入法组字期间禁用格式命令。
- 本轮不修改用户真实简历的内容、样式、头像或分页；仅使用隔离的虚构数据测试工具栏与 PDF。

## 边界

这是 Markdown 辅助工具栏，不是所见即所得富文本编辑器。安全链接仍可通过 Markdown 输入。
不恢复已跳过的干净 Mac 验收；不把内嵌浏览器验证扩大为所有浏览器兼容通过。
