## M1 第一轮实验顺序

1. 清点本机现有开发工具，只作为实验环境；选择并锁定候选 Python/引擎版本。
2. 使用受管理目录验证中文单栏模板、字体及特殊字符，不修改全局 TeX 配置。
3. 编写安装/下载校验实验并在干净 Mac 上复现；记录真实下载量、磁盘占用及离线重编译。
4. 测安全链接、Markdown AST 白名单、TeX 转义、越界文件读取和超时进程树清理。
5. 固定字体、样例和计时方法，至少 30 次热编译，记录冷编译、P50/P95/最大值及许可证清单。
6. 填写 M1 验收记录后才选生产方案；若无干净 Mac，标记对应项未测试，可继续独立实验但不能签署 M1 通过。

M0 不安装新的 LaTeX、不改全局工具版本、不执行真实简历编译、不声称性能或安全验收通过。
