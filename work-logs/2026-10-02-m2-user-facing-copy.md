# M2 用户界面开发文案清理

## 目的与范围

用户要求暂停功能调整，清理普通用户不需要的开发显示内容。本次只改当前应用的界面文案与状态表达，不改历史 M0 原型、数据契约、保存流程、PDF 模板或安装资源。

## 改动

- 去掉顶栏开发版标签；列表、保存状态、预览状态及旧版导出确认不再展示内部修订号。
- 将数据库、服务端和编译等工程说明改成保存、预览和 PDF 生成等操作提示；压缩模块内重复的自动保存说明。
- 删除版式面板的固定间距数值清单和像素换算细节，保留统一留白及预览缩放说明，原有排版参数不变。
- 保留数据仅在本机、备份建议、未保存输入、冲突恢复、旧版导出确认、字体及预览失败提醒。初次生成 PDF 失败和已有旧预览时的失败状态均明确显示。
- 用户简历名称及内容原样保留，包括名称中的测试字样。虚构示例和非真实缩略图仍有明确说明；下载文件名继续保留版本后缀，便于区分文件。
