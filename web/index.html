本地使用说明

停下输入约 1 秒后自动保存。关闭页面前请确认显示“已保存到本机”；PDF 需要点击“保存并预览”更新。

正文框上方提供加粗、斜体、换行、黑点列表和编号列表按钮。先选中文字再设置加粗/斜体；列表作用于当前行或选中多行，再次点击取消。编辑区保留 Markdown 标记：**文字** 显示为粗体，行首“- ”在 PDF 中显示为黑点，不需要自己输入黑点字符。

同一条目中需要另起一行时，将光标放在两段内容之间，点击“换行”或按 Shift+Enter，不需要添加黑点。普通 Enter 是 Markdown 软换行，空一行用于分段。

快捷键：⌘/Ctrl+B 加粗，⌘/Ctrl+I 斜体，Shift+Enter 换行，⌘/Ctrl+Z 撤销，⌘/Ctrl+Shift+Z 重做。撤销/重做仅作用于当前正文框，切换模块后保留，刷新页面后清空；可在格式按钮未启用时继续手写 Markdown。

可以创建多份简历、复制旧版本、上传 PNG/JPEG 头像。工程备份包含已保存的内容和头像，导入始终创建新副本。

上传头像后可拖动、缩放或旋转，裁剪为 3:4 矩形；确认后保存，取消不替换原头像。“调整头像”基于当前已保存的图片，若要恢复裁掉的部分，请重新上传原图。

PDF 生成失败不会丢失已保存内容，仍可查看上次预览。导出上次成功版本需要确认，文件不包含之后的修改。
