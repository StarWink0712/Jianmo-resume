# 2026-10-02：随项目分发的虚构参考简历

## 目的与输入

按用户要求清空当前应用简历库，提供 Java 开发、算法、测试三个带完整正文的虚构参考。其他开发者准备好依赖后首次启动即可使用，也可删除并永久停止自动出现。本批次不扩展研发阶段，不推送远程仓库。

## 实现与决策

- 内容源为 `examples/resumes/` 三份 v1 JSON；`examples/backups/` 同步提供可用主页“导入工程”读取的 `.resume.zip`，全部为虚构资料，无真人照片。默认均为一页 A4，分别使用蓝色、商务灰、青绿色。
- 全新数据库在事务中初始化三份独立 ID 的参考，`app_metadata.bundled_examples` 保存完成状态；不是每次检测列表为空就填充。初始化异常会整体回滚并允许重试。
- 已有数据库不自动插入，包含升级前已经删空的数据库。删除全部后重启仍为空；只有用户主动新建、导入或换全新数据目录时才重新出现。
- 新建窗口保留空白选项并新增三个岗位参考；后端保留旧 `sample` 类型兼容测试及旧调用。`--no-examples` 为隔离测试和希望空库启动的用户提供显式选项，之后普通重启不会补种。
- 真实检查发现中文字体将 U+00B7 间隔点提取为 U+30FB。渲染模板显式让 U+00B7 使用已有随附 Latin 字体，保留准确文字及字形；未放宽 PDF 完整性、字体或溢出检查。
- 算法初稿第二页过空，经目视检查精简重复描述并统一 13px 正文字号，保留教育、技能、实习、两个项目、学术、竞赛与参考说明，最终为完整一页。
