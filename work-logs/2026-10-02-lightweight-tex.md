# 2026-10-02：取消普通用户的完整 MacTeX 依赖

## 目的与方案

用户要求其他电脑从源码启动时只安装必要依赖，不为简历工具下载数 GB 的完整 TeX。

普通安装改为 Python 环境加精简 TeX。后端直接使用已有 Python，不再冻结第二份 Python。字体复用仓库资源；宏包、格式生成输入及其原始源码/许可压缩入 `runtime/tex-support.tar.xz`。只下载两个上游 TeX Live 原始引擎包，总计 16,242,404 字节，提取 `xetex` 和 `xdvipdfmx` 两个必要可执行文件。

## 来源与校验

- 引擎包哈希来自本机已批准 TeX Live 的原始 `tlpobj` 元数据；网络下载再次验证 SHA-512，提取文件再次验证 M1 SHA-256，均不是改变原基线。
- CTAN 镜像用于速度，2026-03-23 日期快照用于固定版本后备；任何源均不能放宽版本、哈希或 HTTPS 要求。
- 仓库不重分发引擎和冻结 Python 二进制，避免把旧本地实验包直接当成已审计公开发行物。支持资源保留源文件头、相关包的 sourcefiles、许可、README、manifest 及包元数据。
- 安装在项目内，格式生成禁网，不读取系统 TeX 或宿主 `.fmt`。全样例 PDF 自检通过后才原子切换当前版本。旧版本保留，失败不启动后端。

## 改动

新增支持资源构建器、轻量安装器及回归测试。默认启动脚本不再调用 Homebrew、系统 TeX、PyInstaller 或冻结运行时构建。同步双语 README、技术启动指南及跨机交接提示词。

## 验证

精简安装与源码启动验证通过，证据为 [lightweight-tex.json](evidence/lightweight-tex.json)。

| 项目 | 结果 |
| --- | --- |

| 离线与搬移 | 使用已验证缓存离线安装，搬移到含中文/空格目录后编译通过 |
| 内容、PDF 与字体 | 9 个有效用例通过，13 个不应渲染输入拒绝，字体嵌入/文字检查通过 |
| 格式来源 | 只读取项目格式，生成时严格匹配原基线 248 项输入 |
| 隔离和恢复 | 7 项文件/网络/shell 隔离检查、4 项超时/进程组恢复检查通过 |
| 性能 | 实际后端编译链路、两页样本 30 次；P50 2.155 秒，P95 2.230 秒，低于 3 秒目标 |

编译搜索树仅保留约 2.3 MiB 的文档宏包；格式专用输入和许可源码移出搜索树，但仍保留供复现与许可查询。初版把这些材料全部放进搜索树，性能采样未达标，修正后完整重跑，未通过的中间结果不作为交付证据。

安装过程遇到的两个差异均已定位并修正：上游 `dvipdfmx` 是符号链接，只选择原始 `xdvipdfmx` 普通文件；格式生成配置放到作业目录，避免将项目配置误算为新增上游源输入。没有删除源校验、改变原引擎哈希或修改已批准 M1 基线。

不操作个人简历库，不推送远端，不将当前机器隔离测试写成干净 Mac 验收。全新环境测试结束后停止服务并清理临时源码，只保留忽略目录的诊断日志。

## 最终应用回归

`scripts/check_pre_push.py --full` 的 25 个步骤全部通过：175 项 Python 测试、74 项 Node 测试、前端语法与契约检查，以及 10 组真实 HTTP/TeX/PDF 回归。结果见 [lightweight-tex-pre-push.json](evidence/lightweight-tex-pre-push.json)。最新标准一页和长两页样例共三页已用 Poppler 渲染并目视检查，无缺字、重叠或裁切。

README 中英文命令一致，4 个命令块通过 shell 语法检查；新文档的本地链接存在，`git diff --check` 通过。原 M1 实现与批准源基线保持不变，新增锁与每个实际源输入再次核对。源码打包只包含 Git 跟踪材料，不包括引擎下载缓存、安装目录、旧冻结包、虚拟环境或个人简历。
