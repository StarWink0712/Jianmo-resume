# 2026-10-01 / M2 / 本地后端与真实流程

状态：本轮后端与集成流程已实现并通过本机验证，M2 产品化尾项未封板。用户明确要求开始后端；沿用其跳过干净 macOS 验收的决定，M1 发布许可/硬隔离等未完成项不被自动标成通过。

本轮目标：SQLite 不可变修订、多简历管理、受保护的 loopback API、真实编译队列、PDF 预览/下载与 ZIP 备份恢复。保留 M0 历史交互稿，新 M2 集成页沿用双栏蓝白视觉。为聚焦后端，集成页先用原生模块脚本，不把这一步包装为已完成 React/TypeScript 的最终前端；后续迁移须复用接口与测试。

仅使用虚构数据验证。默认开发实例的数据放项目 `.local-data/`，不提交数据库、头像、编译原文或服务令牌。只监听 127.0.0.1，令牌不写 URL 和普通日志。编译使用专用 TeX；M2 服务本身暂在项目虚拟环境启动，不宣称已进入 M1 冻结安装包。

## 实现

- FastAPI loopback API，Host/Origin/会话令牌边界、请求上限、安全错误返回、静态白名单。
- SQLite WAL/FULL 事务、不可变修订、期望版本检查、多简历 CRUD、独立副本、头像和 PDF BLOB 持久化。
- 单工作线程编译队列，最多 32 个待处理任务；构建键去重、快照编译、旧结果标记、失败保留上次成功 PDF、退出/重启恢复。
- 真实 PNG/JPEG 上传与去元数据处理、ZIP 工程导出/导入，拒绝穿越/链接/重复/超限/校验错误，不覆盖已有简历。
- 新 `web/` 集成页；1 秒自动保存与显式编译分离，保存冲突可另存副本，后台响应不替换用户继续输入的字段。
- 原内嵌浏览器 PDF iframe 实测空白，改用本地 PDF.js 5.6.205 与 worker，保留原 Apache-2.0 许可，无 CDN。支持真实画布、文本替代、翻页、缩放和同源下载。
- 线程中的 TeX 子进程使用独立可信启动脚本设置资源限制，避免 `preexec_fn` 在多线程进程中死锁；原 M1 默认路径未改变。

真实 HTTP 自检使用隔离临时目录，不碰默认数据目录。覆盖服务启动/重启、令牌轮换、一/两页编译、预览下载一致、独立副本、不可编译草稿保留旧 PDF、带头像恢复到全新数据库并再次编译。结果：[机器记录](../docs/m2/results.json)。

补充并发回归：提交后返回详情必须仍对应当前请求提交的修订。对比两次交错写入，第一响应 r2、第二响应 r3，不能把第二次内容错误确认为第一次保存成功。

浏览器验证新建、自动保存、刷新、真实 PDF、双页、双页面冲突、副本与服务重启续接。修改后的 M2 页面实际使用 SQLite，不再显示“刷新即丢失”的 M0 演示说明。M0 历史稿和原 8765 服务保持不变，真实入口为 8770。

PDF 共三页已渲染目视检查。窄屏覆盖工具未改变实际尺寸，未将其标为移动端通过；Safari/Chrome 完整兼容性同样未通过。具体证据和限制见 [M2 验证](../docs/m2/acceptance.md)。
