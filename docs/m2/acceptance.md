- 本轮没有新增整页浏览器自动化 E2E 脚本，UI 记录属于人工驱动的浏览器检查；React/TypeScript、可编辑富文本工具、完整无障碍体验留待 M3。

- 磁盘完全写满或永久只读时，编译结果状态发布也可能失败；先恢复磁盘可写并重启，再重新编译。硬中断后的临时编译目录尚无自动清理策略。
- 沿用 M1 的 RSS 采样保护而非硬内存上限；总磁盘配额、故障注入全覆盖及最终再分发许可审计尚未完成。
- 真正干净 macOS 安装按用户要求跳过，未恢复该任务，不能标为通过。
