# 主题颜色与版式参数

编辑器的“样式设置”替代原“排版设置”，分为主题颜色、版式参数两个页签。
修改自动保存到当前简历，点击“保存并预览”生成实际 PDF；不是仅修改网页示意图。

## 主题色

专业蓝色系、商务灰色系、经典绿色系、温暖橙色系、优雅红色系、中性色调，每组六色，共 36 色。
也可输入六位 HEX（可省略 `#`，自动转为大写）或使用浏览器原生调色盘。
色块、HEX、调色盘及示意标题同步。颜色仅作用于模块标题和分隔线，姓名及正文保持黑色。
预设偏深色以保证可读性；任意 HEX 不强制对比度，不建议在白纸上使用过浅颜色。

## 版式参数

| 参数 | 新简历默认值 | 后端允许范围 |
| --- | --- | --- |
| 模块标题大小 | 15 px | 固定整数预设 12–24 px |
| 模块内容大小 | 14 px | 固定整数预设 12–20 px |
| 姓名大小 | 22 px | 固定整数预设 18–30 px |
| 正文行高 | 固定 1.35 倍 | 面板不再单独调节；旧值仅为兼容保留 |
| 模块间距 | 5 px | 0–40 px |
| 上/下/左/右页边距 | 25/5/20/20 px | 各 0–120 px |

字号仅提供固定整数预设，不再追加 15.94px 等旧小数值。模块间距和页边距只接受整数（步长 1）。px 是文档尺寸，不随浏览器缩放改变：
`96 px = 1 in = 72 PDF bp`。旧 TeX pt 使用 `72.27 pt/in` 换算，不把 pt、bp、px 混用。
模块内容大小同时控制条目标题、详情和正文；行高按该字号计算。改变字号或边距可能改变页数。

## 固定留白

顶部信息行之间额外 3 px；正文固定 1.35 倍行高；列表项之间额外 2 px；正文相邻段落/列表块之间额外 4 px。
同一模块内的可见条目之间固定 8 px；条目标题与正文之间固定 4 px；教育名称与学历/时间行之间额外 2 px。
这些值由模板统一管理，不新增逐项调节控件。模块间距仍独立可调，字号和页边距控件保留。
首段/首个列表不叠加段落空白，技能与获奖内容继续靠近模块横线。留白变化可能影响分页，长条目仍允许自然跨页。

无效 HEX、空数值、越界数值会标红，保留上次有效设置且禁用面板中的预览按钮，不会把空值保存成零。
浏览器原生调色盘的外观及系统吸管能力由浏览器/操作系统决定。

## 条目标题

公司/项目名称、职位/角色在同一段内显示，名称加粗，日期靠右；有项目链接时保留链接。
学术成果、竞赛成果和新结构自定义模块使用相同规则，字段及旧数据兼容说明见 [成果模块](achievement-modules.md)。
标题与下方段落或列表之间额外留 3 PDF bp（4 px），标题末行与正文首行不直接分页。
内容过长时自然换行，不缩小字号或截断文字；此调整不改变用户保存的内容、头像及版式参数。

## 技能与获奖

专业技能不再需要技能分组；获奖经历不再需要条目标题，直接编辑 Markdown 正文。
新增正式 `awards` 模块类型，并兼容旧 `custom` 的“获奖经历/获奖情况”等明确奖项标题。
旧分组和条目标题不再显示，但原值保留在工程数据及备份中；其他自定义模块的条目标题不受影响。
旧获奖模块在重命名前转换为 `awards`，避免改名后重新出现标题栏。

PDF 跳过空标题，不在首条内容前叠加条目间距。列表起始间距归零，横线后固定 3 bp；
模块之间的额外留白由“模块间距”控制，条目之间固定 6 bp（8 px）。

## 数据兼容

简历 schema 仍为 v1，当前样式为整数制 `version: 3`；旧 pt/mm 和 `version: 2` 小数像素分支继续接受读取。
旧字号换算后选择最接近的固定预设（距离相同时取较小字号），旧间距和页边距四舍五入为整数。
旧 `line_height` 字段继续被契约接受、存储和备份保留，但当前模板统一按 1.35 倍渲染，不再受旧值影响。
只是打开面板或重新编译不会写入或增加修订。首次实际修改样式时保存完整 v3（含固定行高），不再混存旧排版字段。
旧简历的渲染也使用相同整数规则，因此取整可能轻微影响分页；重要旧版 PDF 不会被删除。
姓名使用缩小后的默认值，默认主题为专业蓝，已有自定义主题色不变。
复制/备份/导入完整保留每份简历自己的样式。旧版应用不保证能读取新增样式/获奖类型。
